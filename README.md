# ギターコード v0.0.28

v0.0.26 を基準に、TypeScript 側だけにディレイ機能を追加した版です。

- 0 ms: 3音同時
- 正の値: 1→2→3
- 負の値: 3→1→2（Cならソ→ド→ミ）
- C++ (`multitone.cpp`) は v0.0.26 から変更していません。
- ボタン1=P1、ボタン2=P2、ボタン3=P9
- 出力=P8/P14/P16


## v0.0.29 オリジナル和音
ボタンを選び、3つの周波数を直接入力して割り当てるブロックを追加しました。

例: ボタン1 に 262 Hz・330 Hz・392 Hz を割り当てる → C相当。
ディレイ設定はプリセット和音とオリジナル和音の両方に適用されます。


## v0.0.30 音色（波形）

「音色（波形）を ～ にする」ブロックを追加しました。3出力すべてに共通で適用されます。

- スクエア 50%
- パルス 37.5%
- パルス 25%
- ナローパルス 12.5%
- ウルトラナロー 6.25%

これらは nRF52 のハードウェアPWMのパルス幅を変更する方式です。プリセット和音と3周波数の直接指定の両方に適用されます。


## v0.0.34 演奏モード
- 通常の和音（初期値）
- ユニゾン：3出力とも第1周波数
- 3倍音：第1周波数、2倍、3倍
- 金管（近似）：第1周波数、2倍、3倍 + パルス25%
- モードを設定しない場合は従来どおり「通常の和音」です。


## v0.0.35 ピン割り当て変更
- ボタン1 = P1
- ボタン2 = P2
- ボタン3 = P8
- 出力1 = P12
- 出力2 = P14
- 出力3 = P16

micro:bit V2では P8 は nRF52833 の P0.10、P12 は P0.12 に対応します。


## v0.0.36 ボタン同時押し
ボタンのプルダウンに以下を追加しました。

- ボタン1＋ボタン2
- ボタン2＋ボタン3
- ボタン1＋ボタン3
- ボタン1＋ボタン2＋ボタン3

物理ピン:
- ボタン1 = P1
- ボタン2 = P2
- ボタン3 = P8

同時押しは完全一致で判定します。たとえばボタン1＋ボタン2を押している間は、
ボタン1単独やボタン2単独の割り当ては発音しません。
約15msの安定判定を入れ、同時押し時の誤発音を抑えています。


## v0.0.37 ジョイスティック発音ゲート
### ボタン状態
- ボタンなし
- ボタン1
- ボタン2
- ボタン3
- ボタン1＋ボタン2
- ボタン2＋ボタン3
- ボタン1＋ボタン3
- ボタン1＋ボタン2＋ボタン3

### ジョイスティック
VR1 の接続:
- 6 = 3V
- 5 = micro:bit P0
- 4 = GND

P0 のアナログ値が中央付近（350～674）の間は必ず無音です。
350未満または674より大きいときだけ、現在のボタン状態に割り当てた和音を鳴らします。


## v0.0.38 ジョイスティック方向でストローク順を変更
VR1:
- 6 = 3V
- 5 = P0
- 4 = GND

ディレイが0以外の場合:
- 6側（3V側）へ倒す: 1→2→3（Cなら ド→ミ→ソ）
- 4側（GND側）へ倒す: 2→3→1（Cなら ミ→ソ→ド）

ディレイ値はジョイスティック発音では絶対値を使用します。
ジョイスティックを中央へ戻すか反対側へ切り替えると、一度停止して新しい方向で鳴り直します。


## v0.0.39 逆方向と即時切替
- 6側（3V側）: 1→2→3（Cなら ド→ミ→ソ）
- 4側（GND側）: 3→2→1（Cなら ソ→ミ→ド）
- ディレイ途中でも以下の変化を約5ms単位で監視:
  - ボタン状態の変更
  - ジョイスティック方向の変更
  - ジョイスティックを中央へ戻す
- 変化を検出したら現在の演奏を即停止し、watcherが新しい状態の和音を鳴らします。


## v0.0.40 弦をはじくトリガー方式
ジョイスティックを連続スイッチではなく、1回のストロークを開始するトリガーとして扱います。

- 6側（3V側）: 1→2→3（Cなら ド→ミ→ソ）
- 4側（GND側）: 3→2→1（Cなら ソ→ミ→ド）
- 一度倒して発音が始まったら、中央へ戻しても現在のストロークは最後まで継続します。
- ストローク完了後も現在の3音は保持します。
- 次の発音指示が来たら、現在音を `stopAll()` で強制停止して新しい音を鳴らします。
- 新しい発音指示:
  - 中央から6側または4側へ倒す
  - 6側から4側、または4側から6側へ切り替える
  - 中央へ戻してからもう一度倒す
  - 倒している間に別のボタン組み合わせへ変更する


## v0.0.41 逆側停止帯＋約3秒フェード
### ジョイスティック P0 のゾーン
- 0～349: 4側（GND側）の新ストローク
- 350～469: 4側の停止帯
- 470～553: 中央
- 554～674: 6側の停止帯
- 675～1023: 6側（3V側）の新ストローク

6側から鳴らした音は、中央へ戻しても継続します。
その後4側の停止帯（350～469）へ少し倒すと即停止します。
さらに深く4側（0～349）へ倒すと、逆方向の新しいストロークになります。
4側から鳴らした場合も左右対称です。

新しいストロークや停止操作がなければ、発音後に約3秒かけて疑似フェードアウトします。
フェードはPWMのパルス幅を30段階で狭める方式なので、アナログ音量制御ではなく近似的な減衰です。


## v0.0.42 停止帯を拡大
P0ゾーンを次のように変更しました。

- 0～100: 4側の新ストローク
- 101～469: 4側の停止帯
- 470～553: 中央
- 554～922: 6側の停止帯
- 923～1023: 6側の新ストローク

深く倒す新ストローク領域を各端約100にし、そのぶん停止帯を大きくしています。


## v0.0.43 深いストローク範囲を約30へ縮小
P0ゾーン:
- 0～30: 4側の新ストローク
- 31～469: 4側の停止帯
- 470～553: 中央
- 554～992: 6側の停止帯
- 993～1023: 6側の新ストローク

さらに、発音後に一度中央へ戻った場合は、その次にどちら側へ倒しても新しい音を鳴らさず、現在音を停止します。
停止操作に使った傾きは消費されるため、もう一度中央へ戻してから次のストロークを行います。

## Version 1.0.1
- 自動フェードアウトを約3秒から約2秒へ変更。
- 同じボタン・同じ和音を連続して再発音できるよう修正。
- 発音後に中央へ戻したあと:
  - 停止帯へ少し倒す → 現在音を停止するだけ。
  - 深いストローク領域まで倒す → 現在音を停止し、そのまま新しいストロークとして再発音。
- ディレイ途中でも同じルールで新しいストロークへ切り替え可能。


## Version 1.0.2
- 和音が鳴っている途中でも、一度中央へ戻った後に深いストローク領域まで倒すと、
  現在の音を即停止して同じ和音でも最初から再発音するよう修正。
- ディレイ途中の再ストロークは pending retrigger として予約し、
  旧ストローク終了直後に最優先で新しい和音を鳴らします。
- 音色に「ワイドパルス 93.75%」を追加。
  100%は直流になり音が出ないため、15/16 = 93.75%を採用しています。


## Version 1.0.3

  現在音を即停止して同じ和音でもディレイの1音目から再発音
- ディレイ中は約3ms間隔で再進入を監視


## Version 1.0.4
停止帯の判定を修正しました。

- 4側停止帯: 31～469
- 中央: 470～553
- 6側停止帯: 554～922

発音中は、現在のストローク方向と同じ側の停止帯でも、反対側の停止帯でも即停止します。

## Version 1.0.5
ジョイスティックを発音レンジから中央へ戻す際、同じ側の停止帯を通過して
意図せず音が止まることがある問題を改善しました。

- 発音直後200msは、発音した方向と同じ側の停止帯だけ停止判定を無効化。
- 反対側の停止帯は保護時間中でも停止可能。
- 中央帯に到達した時点で保護を解除。
- 発音レンジの外へ出たことによる再アームは保護時間中も有効。
- そのため、短い間隔で同じ和音を連続ストロークする動作は維持。
